# Deeix-Chat 1.0.0

Android 7.0+ web client for https://chat.stella-wishing.xyz/.

- Swipe right from the left edge on a phone to open the conversation sidebar.
- Keep the web interface clear of the status bar, camera cutout, and navigation controls.
- Support file selection, downloads, sign-in cookies, and camera/microphone requests from the Deeix-Chat origin.

This is a signed production APK. The signing key is retained in a separate private backup,
outside the source repository and this Release.

If you installed an earlier debug APK, uninstall it before installing this production
APK because Android does not allow an app update across different signing identities.
Uninstalling may remove app-local login state. Future production updates should be
signed with the same key.
