# Deeix-Chat 1.1.0

Android 7.0+ WebView client for https://chat.stella-wishing.xyz/.

- Keep page controls below the Android status bar, cutout, and navigation insets while preserving the edge-to-edge appearance.
- Add native loading progress, network error recovery, and WebView renderer recovery.
- Harden WebView file access and navigation handling.
- Improve file upload, downloads, old Android storage compatibility, and Cookie flushing.
- Add configurable HTTPS server addresses and HTTPS/custom Deep Links.
- Add cache clearing, retry, browser-open, and server settings actions.
- Enable release shrinking and resource removal.

Production updates must use the same long-lived signing key as earlier releases.
